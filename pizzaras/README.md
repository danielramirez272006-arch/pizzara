# 🎨 PizarraMastery - Aplicación React + Vite

Para consultar la documentación completa de la aplicación, diagramas de arquitectura de seguridad, sistema de roles (RBAC), características de la pizarra interactiva y guía de uso detallada, consulta el [README principal en la raíz del proyecto](../README.md).

## 🚀 Comandos Rápidos

```bash
# Instalar dependencias
npm install

# Iniciar servidor local en desarrollo
npm run dev

# Compilar para producción
npm run build

# Previsualizar build de producción
npm run preview
```
